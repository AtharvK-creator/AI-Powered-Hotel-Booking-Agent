# AI Powered Hotel Booking Agent

A full stack hotel booking platform powered by Gemini AI and tool calling.

The application allows users to search hotels, create bookings, modify reservations, cancel bookings, and manage booking history through both a traditional interface and an AI assistant.

## Features

User Authentication

Hotel Search and Filtering

Hotel Details and Booking

Booking History

Booking Modification and Cancellation

AI Chat Assistant

Admin Dashboard

Responsive Design
